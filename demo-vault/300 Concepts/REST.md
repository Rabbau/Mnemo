## 🔍 Что это простыми словами
Стиль API, где всё — ресурсы с адресами, а действия — HTTP-методы.

## 📌 Ключевые моменты
- GET читает, POST создаёт, PUT/PATCH меняет, DELETE удаляет
- Сервер не хранит состояние клиента
- Коды ответа несут смысл: 201, 404, 422

## 🧩 Как это работает
Клиент обращается к `/notes/42`, сервер отвечает JSON-представлением ресурса.

## 💻 Пример кода
```python
@app.post('/notes', status_code=201)
async def create_note(note: NoteIn): ...
```
