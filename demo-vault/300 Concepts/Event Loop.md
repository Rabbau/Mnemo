## 🔍 Что это простыми словами
Диспетчер, который по очереди запускает готовые к работе корутины.

## 📌 Ключевые моменты
- Один цикл на поток
- Закрытый цикл нельзя переиспользовать
- asyncio.run создаёт и закрывает цикл

## 🧩 Как это работает
Цикл хранит очередь задач и следит за сокетами: как только данные пришли — продолжает нужную корутину.

## 💻 Пример кода
```python
loop = asyncio.get_running_loop()
loop.call_later(5, print, 'прошло 5 секунд')
```
