## 🔍 Что это простыми словами
Функция, которая «помнит» переменные из места, где её создали, даже когда оттуда уже вышли.

## 📌 Ключевые моменты
- Внутренняя функция захватывает переменные внешней
- На замыканиях построены декораторы
- nonlocal позволяет менять захваченную переменную

## 🧩 Как это работает
Когда внешняя функция возвращает внутреннюю, Python сохраняет ссылки на нужные переменные в `__closure__`.

## 💻 Пример кода
```python
def counter():
    n = 0
    def inc():
        nonlocal n
        n += 1
        return n
    return inc
```
