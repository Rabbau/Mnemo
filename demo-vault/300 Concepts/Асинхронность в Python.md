## 🔍 Что это простыми словами
Способ делать много операций ввода-вывода одновременно в одном потоке: пока ждём сеть, выполняем другое.

## 📌 Ключевые моменты
- async def создаёт корутину
- await отдаёт управление Event Loop
- Подходит для I/O, а не для тяжёлых вычислений

## 🧩 Как это работает
Корутины переключаются в точках await, а [[Event Loop]] решает, кого запускать дальше.

## 💻 Пример кода
```python
async def main():
    async with aiohttp.ClientSession() as s:
        pages = await asyncio.gather(*(fetch(s, u) for u in urls))
```
