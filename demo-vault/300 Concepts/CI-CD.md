## 🔍 Что это простыми словами
Автоматическая проверка и выкладка кода: запушил в main → тесты → деплой.

## 📌 Ключевые моменты
- CI — сборка и тесты на каждый коммит
- CD — автоматическая доставка на сервер
- GitHub Actions — самый простой старт

## 🧩 Как это работает
Пайплайн описывается в YAML и запускается на каждый push.

## 💻 Пример кода
```python
# .github/workflows/deploy.yml
# on: push -> jobs: test -> deploy
```
