## 🔍 Что это простыми словами
Обёртка, которая добавляет функции поведение, не меняя её код.

## 📌 Ключевые моменты
- Декоратор — функция, принимающая функцию
- Работает благодаря замыканиям
- functools.wraps сохраняет имя и docstring

## 🧩 Как это работает
`@timer` над функцией — это то же самое, что `f = timer(f)`.

## 💻 Пример кода
```python
def timer(fn):
    @wraps(fn)
    def wrapper(*a, **kw):
        t = time.perf_counter()
        result = fn(*a, **kw)
        print(time.perf_counter() - t)
        return result
    return wrapper
```
