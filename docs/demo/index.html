Хранилище Obsidian

Модель для чата, агента и шаблонов

Без ключа и без своей модели

  1. Когда нужен ИИ, приложение покажет готовый запрос — нажми «Скопировать».
  2. Вставь его в chat.deepseek.com, chatgpt.com или любой другой чат.
  3. Скопируй ответ кнопкой копирования под ответом (так сохранится разметка) и вставь обратно.
Работают все функции: чат, быстрый ответ, агент, шаблоны, подсказки. Сложные сценарии (агент с шаблонами) займут несколько шагов. Поиск по заметкам — по словам (по смыслу, если запущена Ollama с индексом).
Бесплатно и приватно: заметки не покидают компьютер.
Фрагменты твоих заметок, по которым отвечает ИИ, будут отправляться на сервер провайдера. Поиск и индекс остаются локальными (Ollama).

Ollama локально: поиск по смыслу (эмбеддинги) и локальная чат-модель

Как установить Ollama

  1. Скачай и установи с ollama.com/download
  2. Скачай чат-модель, например: ollama pull qwen2.5:7b (хорошо понимает русский; для слабого ПК — qwen2.5:3b)
  3. Скачай модель для поиска: ollama pull nomic-embed-text (или bge-m3 — лучше для русского)
  4. Нажми «Проверить»

Семантический индекс

Индекс нужен для умного поиска в чате, похожих заметок и подсказок связей. Без него используется обычный поиск по словам. Обновление индексирует только изменённые заметки.
