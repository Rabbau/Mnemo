Mnemo показывает статистику и граф твоей базы Obsidian, находит нужное по смыслу, отвечает на вопросы по заметкам и наводит порядок: ИИ-агент создаёт заметки по твоим шаблонам и расставляет связи.

Что умеет

Работает с обычной папкой Obsidian — никаких плагинов, баз данных и переноса заметок.

Статистика базы

Заметки, связи, теги, папки, тепловая карта активности за год, рост по месяцам. Хабы, сироты, битые ссылки и ссылки на ещё не созданные заметки.

Граф связей

Интерактивный граф с цветами по папкам, подсветкой соседей, поиском и фильтрами. Клик по узлу — карточка заметки.

Найти или вспомнить Ctrl K

«Где я писал про деплой?» — мгновенный поиск по смыслу и словам, а по Ctrl+Enter короткий ответ ИИ со ссылкой на заметку.

Чат с заметками

Спрашивай свою базу знаний: ИИ находит нужные фрагменты и отвечает с опорой на них, показывая источники.

ИИ-агент

«Разбери Inbox», «создай MOC по Python», «свяжи сирот». Агент составляет план, ты подтверждаешь каждое действие, перед правкой делается бэкап.

Твои шаблоны

Понимает Templater и папочные шаблоны: агент сам выбирает подходящий шаблон, кладёт заметку в нужную папку и заполняет разделы, не ломая структуру.

ИИ — как тебе удобно

Переключается в настройках в один клик. Поиск по смыслу всегда работает локально.

Через Ollama на твоём компьютере. Заметки никуда не уходят.

  • Бесплатно и офлайн
  • Хватает видеокарты на 6 ГБ (qwen2.5:7b)

  • Самые сильные модели
  • Ответы за секунды
  • На OpenRouter есть бесплатные модели

Веб-чат

Нет ни ключа, ни видеокарты? Mnemo готовит запрос, ты вставляешь его в chat.deepseek.com и возвращаешь ответ.

  • Совсем бесплатно
  • Работают все функции

Установка за 3 шага

Нужен только Python 3.10+. Работает на Windows, macOS и Linux.

Скачай

git clone https://github.com/Rabbau/Mnemo
cd Mnemo

Запусти

Windows — двойной клик по run.bat. Linux и macOS:

./run.sh

Откроется 127.0.0.1:8765

Подключи

В настройках выбери своё хранилище Obsidian — Mnemo найдёт его сам. Для локального ИИ:

ollama pull qwen2.5:7b
ollama pull bge-m3

🔒 Заметки остаются твоими

Mnemo работает на твоём компьютере и читает обычные .md файлы. С локальной моделью ничего не покидает машину, в облачных режимах уходят только найденные фрагменты заметок, а не всё хранилище.

🛟 Безопасные изменения

Агент ничего не меняет без подтверждения. Перед каждой правкой файл копируется в бэкап, «удаление» — это перенос в .trash, а при переименовании обновляются все ссылки.
